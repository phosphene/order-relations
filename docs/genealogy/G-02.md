# G-2 — Adiabatic Elimination (Canonical): Briggs–Haldane QSSA

**Unit:** `docs/genealogy/G-02.md` · **Script:** `scripts/genealogy/g2_michaelis_menten.R`
**Verdict:** ✅ reproducible (numerical) · **Tier:** elimination

## Precursor (as published)

Michaelis & Menten (Biochem. Z. **49**, 333; 1913); Briggs & Haldane
(Biochem. J. **19**, 338; 1925). Enzyme–substrate system:

    dS/dt = −k₁ES + k₋₁C
    dC/dt =  k₁ES − (k₋₁+k₂)C,   E = E₀ − C

## Derivation (the precursor math)

Quasi-steady-state assumption: the fast complex C relaxes quickly, so
dC/dt ≈ 0. Eliminate C:

    C = E₀S/(Km + S),   v = k₂C = Vmax·S/(Km + S),
    Km = (k₋₁+k₂)/k₁,   Vmax = k₂E₀

This is the **canonical published standard** for "fast variable eliminated in
the field of the slow one" — the exact operation our `effective_dynamics()`
performs on the flytrap instantiation.

## Code

```r
# Explicit Euler on the full 2-variable ODE; compare dP/dt to the
# closed-form MM rate at the same substrate level, post-transient.
for (i in seq_len(n)) {
  E  <- E0 - C
  dS <- -k1*E*S + km1*C
  dC <-  k1*E*S - (km1+k2)*C
  dP <-  k2*C
  S <- S + dS*dt; C <- C + dC*dt; P <- P + dP*dt
}
v_full <- diff(P)/dt
v_mm   <- Vmax * S / (Km + S)
```

## Results (run `Rscript scripts/genealogy/g2_michaelis_menten.R`)

    Km = 0.6, Vmax = 0.05 (k₁=1, k₋₁=0.1, k₂=0.5, E₀=0.1, S₀=1)
    full ODE dP/dt vs MM closed form, max relative error in QSSA window: 0.037

## Verdict

Reproducible. The elimination holds post-transient (error < 4%); the
pre-transient mismatch is the fast binding phase — exactly the regime where
QSSA is not expected to hold.
