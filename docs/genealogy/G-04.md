# G-4 — Critical Slowing Down: Relaxation Time Divergence

**Unit:** `docs/genealogy/G-04.md` · **Script:** `scripts/genealogy/g4_critical_slowing.R`
**Verdict:** ✅ reproducible (slope −0.9964 vs −1) · **Tier:** dynamics

## Precursor (as published)

S. Strogatz, *Nonlinear Dynamics and Chaos* (1994), ch. 3 & 8. For the
supercritical pitchfork normal form ẋ = rx − x³, the linearized decay rate at
the stable equilibrium is |r|, so the relaxation time diverges as τ ~ 1/|r|
as r → 0 (for the saddle-node ẋ = r + x² the scaling is |r|^(−1/2)).

## Derivation (the precursor math)

Linearize about the stable fixed point: ẋ ≈ r·x for r < 0 (decay to 0) ⇒
x(t) ~ e^(−|r|t) ⇒ τ = 1/|r|. Test: measure time to settle to 1% of the
initial amplitude, across |r|; the log–log slope must be −1.

## Code

```r
relax_time <- function(r, x0 = 0.05, dt = 1e-3, tmax = 2000) {
  x <- x0; t <- 0
  for (i in seq_len(tmax / dt)) {
    x <- x + (r*x - x^3)*dt; t <- t + dt
    if (abs(x) < 0.01 * x0) break
  }
  t
}
```
