## Precursor (as published)

Laland, K.N., Odling-Smee, F.J., & Feldman, M.W. (1999). "The evolutionary
consequences of niche construction: a theoretical investigation across two
loci." *PNAS* 96(18):10242–10247. DOI 10.1073/pnas.96.18.10242.
Founding two-locus version: Laland, Odling-Smee & Feldman (1996),
*J. Evol. Biol.* 9:293–316 (recursion form reconstructed via the 1999
λ₂ = 1/n reduction; primary PDF not yet obtained).

## Model (verified verbatim against primary full text)

Two diallelic loci: modifier (E/e) and recipient (A/a). Haplotypes
x₁..x₄ = (EA, Ea, eA, ea); p = x₁+x₂, q = x₁+x₃, D = x₁x₄ − x₂x₃.

Environmental state (Eq. 1, two regimes):

    increment:  R_t = λ₁R_{t−1} + λ₂p_t + λ₃
    decrement:  R_t = λ₁R_{t−1}(1 − γp_t) + λ₃

Constraints: 0 < λ₁, λ₂, λ₃, γ < 1; λ₁ + λ₂ + λ₃ ≤ 1.

Fitness (Table 1, verified verbatim): fixed multiplicative component
(α₁, α₂, β₁, β₂) plus frequency-dependent component with strength
−1 < ε < 1. **Critical transcription note:** the heterozygote row carries
the *bare* ε term — AA·** gets εR, Aa·** gets ε, aa·** gets ε(1−R). The
sum structure across the A-locus genotype classes is what generates the
line of polymorphic equilibria q̂ = R (verified to 4.4e-16).

## Analytic results used as verification targets

- Resource equilibrium at fixed p (Eqs. 3a/3b):
  increment: R̂ = (λ₂p + λ₃)/(1 − λ₁); decrement: R̂ = λ₃/(1 − λ₁(1 − γp)).
- "No selection on E" (α₁ = β₁ = 1) ⇒ p invariant **only when D = 0**;
  with D ≠ 0 the modifier allele hitchhikes on the selected recipient
  background (documented finding; paper prose is loose here).
- λ₂ = 1/n, λ₁ = 1 − 1/n reproduces the 1996 weighted-average
  ("primacy") resource model exactly — `primacy_weights(n)`.
- Neutral LD decays as (1−r)^t (standard result, verified 1e-12).

## Verification findings (workspace battery + package tests)

1. **Battery design:** neutral checks (normalization, LD decay) are
   structurally blind to haplotype-indexing errors; only
   fitness-coupled checks catch them. Five of ten pair→genotype
   mappings were transposed in the first draft and V1/V3 passed anyway.
2. **Iteration budget (the NCT-vs-numerics tension):** iterations to
   equilibrium = log(ε)/log(λ₁) — 20 generations at λ₁ = 0.5 but
   13,809 at λ₁ = 0.999. Published-style short runs are transients
   masquerading as equilibria in exactly the long-memory regime the
   theory is about.
3. **Stiffness:** ODE embedding (Euler of the map, dR/dt exact) at
   λ₁ = 0.99 is stiff — forced BDF beats forced Adams (deSolve LSODA's
   Adams↔BDF toggle fires where it should). The discrete map remains
   the verification standard; the ODE is a lens.
4. **Spatial well-mixed limit (ReacTran):** the 1999 R-recursion is
   exact for the domain mean at every D, but local heterogeneity grows
   0.003 → 0.32 as D → 0.001. The paper's "extremely simplified"
   resource caveat, quantified. See workspace spatial battery V10–V13.

## Instantiation boundary

`eco_inheritance.R` contains zero biological nouns: a modifier
frequency p, an environmental state R, a caller-supplied 3×3 fitness
matrix (function of state), and the two-regime map. The 1999 E/A
instantiation (loci E and A, resource R, Table 1) lives in
`test-eco-inheritance.R` and this document.

## Composition hooks

- `resource_map()` / `resource_equilibrium()` / `primacy_weights()` —
  the environmental half, composable with any selection half.
- `two_locus_step()` / `two_locus_run()` — the coupled recursion with
  caller-supplied W(R). Feedback is first-class: W is a function of R.
- Tension instruments from the same session: iteration-budget check
  (V8), LSODA stiffness lens (V9), ReacTran spatial substrate (V10–V13).
