# G-9 — Center Manifold Reduction: The Exact Slaving Manifold

**Unit:** `docs/genealogy/G-09.md` · **Script:** `scripts/genealogy/g9_center_manifold.R`
**Verdict:** ✅ reproducible (exact, machine precision) · **Tier:** elimination (rigorous)

## Precursor (as published)

Strogatz, *Nonlinear Dynamics and Chaos*, ch. 8 (Center Manifold Theorem);
Guckenheimer & Holmes, *Nonlinear Oscillations*, ch. 3. Near a bifurcation
the fast stable direction relaxes onto a manifold x = h(y) tangent to the
slow subspace; the reduced dynamics on the manifold capture the essential
behavior.

## Derivation (the precursor math)

Prototype: ẋ = −x + y²; ẏ = y. Eigenvalues −1 (fast, stable) and +1
(slow/unstable) — hyperbolic-fast, nonhyperbolic-slow.

Center manifold equation h'(y)·ẏ = −h(y) + y², i.e. h'(y)·y = −h(y) + y²:

    h(y) = y²/3   (exact: (2y/3)·y = 2y²/3 = −y²/3 + y²)

Reduced dynamics on the manifold: ẏ = y — the fast variable **leaves no
trace** in the slow dynamics. Exact full solution (y is linear):

    x(t) = y₀²·e^(2t)/3 + u₀·e^(−t),   u₀ = x₀ − y₀²/3

— a curved-manifold component growing as e^(2t) plus an off-manifold
component decaying as e^(−t).

## Code

```r
# Exponential integrator (exact integrating factor per substep):
# x(t+h) = x·e^(−h) + y²·e^(−h)(e^(3h) − 1)/3
# solves ẋ = −x + y² exactly given y(t) = y₀·e^t.
x <- x*exp(-h) + y^2*exp(-h)*(exp(3*h) - 1)/3
y <- y*exp(h)
```

    manifold equation residual:            max = 3.55e−15  (machine zero)
    off-manifold decay u vs u₀·e^(−t):     max rel err = 1.67e−9
    on-manifold capture x vs y₀²·e^(2t)/3: max |err|  = 1.57e−10

## Verdict

Reproducible — exact. The manifold is exactly quadratic (not asymptotic);
off-manifold modes decay as e^(−t); the reduced 1-D dynamics match the full
2-D system. This is the *rigorous* version of G-3's slaving: the center
manifold IS the slaving manifold, computed exactly instead of asymptotically.
