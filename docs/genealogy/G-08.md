# G-8 — Systematic Elimination: van Kampen's Order-by-Order Expansion

**Unit:** `docs/genealogy/G-08.md` · **Script:** `scripts/genealogy/g8_van_kampen.R`
**Verdict:** ✅ reproducible (O(ε) per order) · **Tier:** elimination (rigorous)

## Precursor (as published)

N.G. van Kampen, "Elimination of fast variables", *Phys. Rep.* **124**, 69 (1985).
The slaving manifold is computed **order by order** in ε; each order removes
one power of ε from the reduction error. Our reproduction is the
ODE/Langevin-level expansion — the full master-equation operator machinery is
a stated scope limit.

## Derivation (the precursor math)

Prototype (same as G-3): ẋ = −(1/ε)(x − ay); ẏ = −y + bx.

    Zeroth order:  x* = a·y,             ẏ = r₀·y,  r₀ = ba − 1
    First order:   x* = a·y − ε·a·(ba−1)·y,
                   ẏ = r₁·y,  r₁ = (ba−1)(1 − ε·ab)

Exact slow eigenvalue of the full 2×2 Jacobian:

    λ_s = [Tr + √(Tr² − 4Det)]/2,  Tr = −(1/ε) − 1,  Det = (1 − ab)/ε

## Code

```r
slow_eigenvalue <- function(eps, a, b) {
  Tr <- -(1/eps) - 1; Det <- (1 - a*b)/eps
  (Tr + sqrt(Tr^2 - 4*Det)) / 2
}
# Compare |r0 − λ_s| (should be O(ε)) vs |r1 − λ_s| (should be O(ε²))
```

## Verdict

Reproducible. Order-by-order elimination confirmed: each order removes one
power of ε from the rate error (9.95× and 99.7× — textbook O(ε) and O(ε²)).
