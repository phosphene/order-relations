# G-6 — Bi-Exponential Relaxation: The Two-Rate Standard

**Unit:** `docs/genealogy/G-06.md` · **Script:** `scripts/genealogy/g6_biexponential.R`
**Verdict:** ✅ reproducible (within noise) · **Tier:** dynamics

## Precursor (as published)

The sum-of-two-exponentials decay

    y(t) = A₁·e^(−k₁t) + A₂·e^(−k₂t),   k₁ ≫ k₂

— the standard two-rate form across NMR (T₁/T₂), chemical kinetics, and
trait-decay fits (LTEE-style). The reproducibility question: given data
generated at known parameters, does nonlinear least squares recover them?

## Derivation (the precursor math)

No closed-form parameter solution exists — recovery is a numerical inverse
problem. The two timescales are identifiable only when k₁ ≫ k₂ and the
sampling window covers both; this is the identifiability boundary that T-2
(window collapse) quantifies.

## Code

```r
set.seed(42)
y <- A1*exp(-k1*t) + A2*exp(-k2*t) + rnorm(length(t), 0, 0.005)
fit <- nls(y ~ a1*exp(-b1*t) + a2*exp(-b2*t),
           start = list(a1=0.5, a2=0.5, b1=0.8, b2=0.1))
```

## Results (run `Rscript scripts/genealogy/g6_biexponential.R`)

    truth:      A₁=0.7  A₂=0.3  k₁=1.0  k₂=0.05
    recovered:  0.703   0.299   0.991   0.0500
    max |truth − recovered|: 0.0086 (within noise)

## Verdict

Reproducible — with a recorded caveat: recovery degrades as k₁/k₂ → 1 or as
the slow phase dominates the window. The identifiability boundary is exactly
what T-2 (window collapse) quantifies — the two tests are a matched pair.
