# G-5 — Order-Parameter Formation: The Pitchfork Amplitude Equation

**Unit:** `docs/genealogy/G-05.md` · **Script:** `scripts/genealogy/g5_pitchfork.R`
**Verdict:** ✅ reproducible (closed form matches integration) · **Tier:** dynamics

## Precursor (as published)

Landau's amplitude equation — the time-dependent generalization of G-1; normal
form in Strogatz ch. 3. The slow mode is *born* at the instability, growing
from fluctuations:

    dψ/dt = αψ − βψ³,   α, β > 0

## Derivation (the precursor math)

Closed form from initial amplitude ψ₀:

    ψ(t) = √(α/β) / √(1 + C·e^(−2αt)),   C = (α/β − ψ₀²)/ψ₀²

Saturates at √(α/β); logistic-shaped with inflection at ψ = √(α/(3β)).

## Code

```r
# Closed form vs explicit Euler on the same equation.
y_closed <- sqrt(alpha/beta) / sqrt(1 + C * exp(-2*alpha*t))
y_num    <- euler_pitchfork(t, y0, alpha, beta)
max(abs(y_closed - y_num))
```

## Results (run `Rscript scripts/genealogy/g5_pitchfork.R`)

    α = 0.1, β = 1, ψ₀ = 0.01
    max |closed-form − numeric| over t ∈ [0, 60]: 1.52e−5
    saturation √(α/β) = 0.3162 | closed-form tail: 0.3153

## Verdict

Reproducible. The closed form matches numerical integration; the tail
approaches √(α/β) as predicted.
