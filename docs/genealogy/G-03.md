# G-3 — Slaving Principle: Haken's Fast-Variable Elimination

**Unit:** `docs/genealogy/G-03.md` · **Script:** `scripts/genealogy/g3_haken_slaving.R`
**Verdict:** ✅ reproducible (O(ε) convergence) · **Tier:** elimination

## Precursor (as published)

H. Haken, *Synergetics: An Introduction* (Springer 1977/1983), ch. 7. Fast
variables relax onto a manifold set by the slow variables; the slow equation
then closes on the reduced dynamics.

## Derivation (the precursor math)

Prototype (linear-nonlinear mixed, the simplest published form):

    ẋ = −(1/ε)(x − ay)     (fast: x tracks ay)
    ẏ = −y + bx            (slow)

Adiabatic elimination: x\* = ay ⇒ reduced dynamics ẏ = (ba−1)y.
The elimination is exact as ε → 0; at finite ε the error is O(ε).

## Code

```r
# Integrate full 2-variable system and reduced 1-variable system;
# compare y(t).
xdot <- -(1/eps) * (x - a*y)
ydot <- -y + b*x
yred <- yred + ((b*a - 1) * yred) * dt
```

## Results (run `Rscript scripts/genealogy/g3_haken_slaving.R`)

    eps = 0.01: max |y_full − y_reduced| = 9.90e−3
    eps = 0.001: max |y_full − y_reduced| = 1.00e−3

## Verdict

Reproducible. Error scales linearly in ε, exactly as the principle states.
