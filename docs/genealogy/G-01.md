# G-1 — Order Parameter (Static): Landau's Free-Energy Expansion

**Unit:** `docs/genealogy/G-01.md` · **Script:** `scripts/genealogy/g1_landau.R`
**Verdict:** ✅ reproducible (analytic) · **Tier:** structure

## Precursor (as published)

L.D. Landau, "On the theory of phase transitions" (Zh. Eksp. Teor. Fiz. **7**, 19; 1937).
The order parameter φ minimizes a free energy expanded in even powers:

    F(φ) = F₀ + a(T−Tc)φ² + bφ⁴,   b > 0

## Derivation (the precursor math)

Stationarity dF/dφ = 0:

    φ[2a(T−Tc) + 4bφ²] = 0

- T > Tc: only φ\* = 0 (disordered).
- T < Tc: φ\* = ±√(a(Tc−T)/2b) (ordered) — the order parameter **emerges
  continuously** from zero as T crosses Tc: φ\* ~ (Tc−T)^(1/2).

## Code

```r
landau_phi_star <- function(T, Tc, a, b) {
  coeff <- a * (T - Tc)
  if (coeff >= 0) return(0)
  sqrt(-coeff / (2 * b))
}
```
